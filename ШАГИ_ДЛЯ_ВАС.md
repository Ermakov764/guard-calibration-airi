## Шаг 1. Hugging Face (5 мин, один раз)

3. Откройте https://huggingface.co/datasets/allenai/wildguardmix

## Шаг 2. Colab — вставить токен (2 мин)

1. В Colab слева нажмите **🔑 Secrets** (ключ)
2. **+ Add new secret**
3. Name: `HF_TOKEN` (точно так, большими буквами)
4. Value: вставьте скопированный `hf_...`
5. Включите переключатель **Notebook access** (доступ для ноутбука)

## Шаг 3. GPU (30 сек)

1. **Среда выполнения → Сменить среду выполнения**
2. **T4 GPU** → Сохранить

Справа внизу должно быть: `T4`.

---

## Шаг 4. Запуск (вы нажимаете, ждёте)

1. Меню **Среда выполнения → Выполнить все** (или Ctrl+F9)
2. На вопрос «Restart session?» → **Да**

**Смотрите вывод ячеек:**

| Ячейка | Должно быть |
|--------|-------------|
| HF login | `HF login OK` |
| GPU | `cuda` и `Tesla T4` |
| Данные | `n= 300` (или >50), не `n= 0` |
| Модель | грузится ~5–15 мин (долго — нормально) |
| Последняя | скачивание `guard_scores.csv` |

Если ошибка **CUDA out of memory** при загрузке модели:

1. **Среда → Перезапустить среду** (обязательно — иначе в GPU остаётся ~14 GB от прошлой попытки)
2. Снова **Выполнить все**
3. Если снова OOM: в ячейке загрузки модели поставьте `COLAB_FORCE_FALLBACK = True` и перезапустите среду ещё раз
4. Или уменьшите `N_SAMPLES` до `50`
